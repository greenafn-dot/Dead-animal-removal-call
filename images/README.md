# Photographs

The cards on this site draw a labelled illustration by default. Drop a real
photograph in here and it takes over automatically — no code change needed.

- Name the file after the animal's `id` in `assets/animals.js`, with a `.jpg`
  extension: `raccoon.jpg`, `opossum.jpg`, `crow.jpg`, and so on.
- Landscape crops work best; cards use a 5:3 box and cover-fit the image.
- Keep them modest in size (roughly 800px wide is plenty) so the page stays
  fast on a phone at the roadside.

If a file is missing or fails to load, the illustration stays visible, so a
partial set of photographs is fine.

## Sourcing

Use images you have the right to publish. Wikimedia Commons carries suitable
photographs of every species listed here under CC or public-domain terms —
record the photographer and licence for each one you use, and credit them.
